# proving local

내 컴퓨터나 갤럭시에서 proving을 실행해 AI와 공부하고, 공부 기록과 시험지를 관리하는 앱입니다. 저장한 내용은 연결한 proving 사이트 계정에서도 볼 수 있습니다.

처음 한 번 설치하고 계정을 연결하면, 다음부터는 앱을 실행하는 명령만 입력하면 됩니다. 별도의 서버나 데이터베이스를 설정할 필요는 없습니다. **사용할 때는 인터넷 연결이 필요합니다.**

## 시작하기 전에

- 기록을 저장할 **본인 GitHub 계정**이 필요합니다.
- AI는 **ChatGPT 계정** 또는 **OpenAI API 키**로 연결합니다. 두 가지를 모두 준비할 필요는 없습니다.
- [proving-local 저장소](https://github.com/yeaseul7/proving-local)가 본인 GitHub 계정으로 열리는지 확인하세요. 비공개 저장소라면 접근 권한이 있어야 설치할 수 있습니다.

이 문서의 **터미널**은 명령어를 입력하는 앱을 뜻합니다. 명령어는 코드 상자 안의 내용을 **한 줄씩 붙여 넣고 Enter**를 누르면 됩니다. 설치가 끝나 다음 명령을 입력할 수 있을 때까지 기다려 주세요.

사용할 기기에 맞는 설치 방법 하나를 따라가세요.

- **Windows·Mac:** 아래의 ‘컴퓨터에 설치하기’
- **갤럭시·덱스:** 아래의 ‘갤럭시에 설치하기’

## 1-A. 컴퓨터에 설치하기 — Windows·Mac

### 필요한 프로그램 설치

1. [Node.js 공식 사이트](https://nodejs.org/)에서 **LTS 버전**을 설치합니다. 함께 설치되는 npm도 필요합니다. Node.js는 **22.6 이상**이어야 합니다.
2. [Git 공식 사이트](https://git-scm.com/downloads)에서 운영체제에 맞는 Git을 설치합니다. Git은 앱을 내려받고 업데이트할 때 사용하는 프로그램입니다.
3. 설치 후 터미널을 새로 엽니다.
   - Windows: 시작 메뉴에서 **PowerShell** 검색
   - Mac: Spotlight에서 **터미널** 검색

설치가 잘 됐는지 확인합니다. 세 명령 모두 버전 번호가 나오면 준비된 것입니다.

```sh
node --version
npm --version
git --version
```

### 앱 내려받고 처음 실행하기

앱을 보관할 폴더에서 터미널을 열고 다음을 실행합니다.

```sh
git clone https://github.com/yeaseul7/proving-local.git
cd proving-local
npm ci
npm run build
npm start
```

각 명령의 뜻은 다음과 같습니다.

| 명령 | 하는 일 |
| --- | --- |
| `git clone ...` | 앱을 컴퓨터에 내려받습니다. 처음 한 번만 실행합니다. |
| `cd proving-local` | 내려받은 앱 폴더로 들어갑니다. |
| `npm ci` | 앱 실행에 필요한 파일을 설치합니다. |
| `npm run build` | 내려받은 앱을 실행할 수 있는 형태로 준비합니다. |
| `npm start` | 앱을 켭니다. |

처음 설치할 때는 다운로드와 준비 작업에 시간이 걸릴 수 있습니다. 마지막 명령을 실행한 뒤 `Ready` 또는 `http://127.0.0.1:3005`가 표시되면, 터미널을 켜둔 채 브라우저에서 [앱 열기](http://127.0.0.1:3005)를 누르세요.

이제 아래의 **‘2. 기록을 저장할 사이트 계정 연결하기’**로 이동합니다.

## 1-B. 갤럭시에 설치하기 — 휴대전화·태블릿·덱스

**갤럭시 안에서 앱 실행 프로그램까지 직접 켜는 방법입니다. 별도의 PC나 Ubuntu 설치는 필요하지 않습니다.** 덱스를 사용한다면 같은 갤럭시의 브라우저를 큰 화면에서 열면 됩니다.

이 방법은 **Android 16 ARM64 가상 기기에서 설치·실행·화면 표시를 확인**했습니다. 삼성 갤럭시·One UI·덱스 실기기와 실제 ChatGPT 계정 로그인 완료까지 확인한 것은 아닙니다.

### Termux 설치

[Termux 공식 안내](https://github.com/termux/termux-app#installation)를 따라 Termux를 설치합니다. Termux는 갤럭시에서 아래 명령어를 실행할 수 있게 해주는 터미널 앱입니다. 공식 안내의 F-Droid 또는 GitHub 배포본을 사용하세요.

### 실행에 필요한 프로그램 설치

Termux를 열고 한 줄씩 실행합니다.

```sh
pkg update
pkg upgrade -y
pkg install nodejs-lts npm git
```

첫 설치에서는 업데이트할 패키지나 확인 메시지가 나올 수 있습니다. 업데이트와 설치가 끝난 뒤 버전 번호가 표시되는지 확인합니다.

```sh
node --version
npm --version
git --version
```

### 앱 내려받고 처음 실행하기

**Termux 안에서** 다음을 실행합니다. 다운로드 폴더나 SD 카드로 옮기지 않고, 아래 명령으로 만드는 기본 폴더를 그대로 사용하세요.

```sh
cd ~
git clone https://github.com/yeaseul7/proving-local.git
cd proving-local
npm ci
npm run build
npm start
```

`Ready` 또는 `http://127.0.0.1:3005`가 표시되면 **같은 갤럭시의 Chrome 또는 삼성 인터넷**에서 [앱 열기](http://127.0.0.1:3005)를 누릅니다. 실제 Android 화면 검증에는 Chrome을 사용했습니다.

- `127.0.0.1`은 **지금 사용하는 갤럭시 자신**을 뜻합니다. PC 주소를 입력하는 것이 아닙니다.
- Termux에서 앱이 실행 중이어야 브라우저에서도 열립니다.
- Android가 Termux를 종료하면 앱도 멈춥니다. 사용 중 자주 끊기면 기기의 배터리 설정에서 Termux의 백그라운드 실행 제한을 확인하세요. 장시간 실행은 실기기에서 별도 확인이 필요합니다.

이제 아래에서 사이트 계정을 연결합니다.

## 2. 기록을 저장할 사이트 계정 연결하기

처음 한 번, 이 기기를 본인의 proving 계정과 연결합니다.

1. [proving 사이트](https://proving.mynameis.life)에 본인 GitHub 계정으로 로그인합니다.
2. **설정 → 연결된 기기 → 연결 코드 발급**을 누릅니다.
3. 앱의 [사이트 계정 연결 화면](http://127.0.0.1:3005/connect)을 엽니다.
4. 발급받은 코드를 입력하고 **이 계정으로 연결**을 누릅니다.

연결 코드는 **발급 후 10분 동안 한 번만** 사용할 수 있습니다. 만료되면 새 코드를 발급받으세요.

연결하면 사이트에 있던 프로필·공부 기록을 앱에서도 사용할 수 있습니다. 앱에서 저장하거나 수정한 내용도 같은 계정에 반영됩니다. 컴퓨터와 갤럭시를 모두 쓴다면 **기기마다 한 번씩** 연결합니다.

## 3. AI 연결하고 공부하기

**사이트 계정 연결과 AI 연결은 서로 다른 단계**입니다.

| 연결 | 필요한 이유 |
| --- | --- |
| 사이트의 연결 코드 | 공부 기록을 어느 proving 계정에 저장할지 정합니다. |
| ChatGPT 계정 또는 OpenAI API 키 | 질문에 답하고 시험지를 만드는 AI를 사용합니다. |

### ChatGPT 계정으로 사용하기

1. 앱의 **공부 중** 화면을 엽니다.
2. **ChatGPT 플랜으로 시작하기**를 누릅니다.
3. 브라우저에서 본인 ChatGPT 계정으로 로그인하고 사용을 승인합니다.
4. 앱으로 돌아오면 모델을 선택하고 질문합니다.
5. 공부를 마치고 **기록하기**를 누르면 공부 내용이 저장됩니다.

실제 AI 사용 가능 여부와 사용량은 본인 ChatGPT 계정·플랜과 승인 조건에 따릅니다. 갤럭시의 실제 계정 로그인 완료는 아직 별도 검증이 필요합니다.

### OpenAI API 키로 사용하기

**설정 → GPT API 키 관리**에서 본인 키를 등록한 뒤, 공부 화면에서 **GPT**를 선택합니다. 사이트에 이미 등록한 키도 사용할 수 있습니다. API 키는 연결한 사이트 서버에 암호화되어 저장됩니다.

## 다음부터 앱 켜기

처음 설치했던 것처럼 매번 전부 설치할 필요는 없습니다. 터미널 또는 Termux를 열고 **처음 앱을 설치한 폴더로 이동한 뒤** 실행합니다.

갤럭시에서 위 안내대로 설치했다면:

```sh
cd ~/proving-local
npm start
```

컴퓨터에서는 설치한 `proving-local` 폴더에서 터미널을 열고:

```sh
npm start
```

같은 기기의 브라우저에서 [http://127.0.0.1:3005](http://127.0.0.1:3005)를 엽니다. 일반적으로 계정 연결을 매번 다시 할 필요는 없습니다.

## 앱 끄기

실행 중인 터미널에서 **Ctrl+C**를 누릅니다. 갤럭시에서는 Termux의 **CTRL** 키를 누른 뒤 **c**를 누를 수도 있습니다. 종료한 뒤에는 로컬 주소가 열리지 않는 것이 정상입니다.

사이트에서 기기 연결을 해제했거나 앱에서 로그아웃했다면 다시 연결 코드가 필요합니다. ChatGPT 승인이 만료되거나 철회됐을 때도 AI 연결을 다시 진행해야 합니다.

## 새 버전으로 업데이트하기

새 버전이 나와도 **기기에 설치한 앱은 저절로 바뀌지 않습니다.**

1. 실행 중인 앱을 **Ctrl+C**로 끕니다.
2. 설치한 `proving-local` 폴더에서 아래 명령을 한 줄씩 실행합니다.

```sh
git pull --ff-only
npm ci
npm run build
npm start
```

3. 브라우저를 새로고침합니다.

일반적인 업데이트로 계정 연결이 해제되지는 않습니다. 로그인·기기 연결 정보가 들어 있는 **`.local` 폴더는 삭제하지 마세요.**

ZIP으로 내려받으면 위의 `git pull` 업데이트를 사용할 수 없습니다. 이 안내대로 `git clone`으로 설치하는 방식을 사용하세요.

## 문제가 생겼을 때

| 증상 | 해결 방법 |
| --- | --- |
| `node`, `npm`, `git`을 찾을 수 없음 | 컴퓨터는 필요한 프로그램 설치 후 터미널을 다시 엽니다. 갤럭시는 Termux에서 프로그램 설치 단계를 다시 확인합니다. |
| `Repository not found` 또는 저장소 접근 오류 | 브라우저에서 GitHub 로그인 후 저장소가 열리는지 확인합니다. 접근 권한이나 터미널의 GitHub 인증이 필요할 수 있습니다. |
| `package.json`이나 `package-lock.json`을 찾을 수 없음 | 앱 폴더 밖에서 실행한 경우입니다. `proving-local` 폴더 안으로 이동한 뒤 다시 실행합니다. |
| `Could not find a production build` | 먼저 `npm run build`가 성공해야 합니다. 끝난 뒤 `npm start`를 실행합니다. |
| `3005` 포트를 이미 사용 중이라고 함 | 앱이 이미 켜져 있을 수 있습니다. 브라우저로 열어보거나, 먼저 켜둔 터미널에서 Ctrl+C로 종료합니다. |
| 갤럭시에서 `Turbopack is not supported` | 개발용 명령을 실행한 경우입니다. 일반 사용은 `npm run build` 후 `npm start`를 사용합니다. 개발 모드가 필요하면 `npm run dev -- --webpack`을 사용합니다. |
| 갤럭시에서 Node.js 실행 시 `cannot locate symbol` | Termux에서 `pkg update`와 `pkg upgrade -y`로 기본 프로그램을 갱신한 뒤 다시 실행합니다. |
| 설치 중 공간 부족 오류가 남 | 기기의 저장 공간을 확보한 뒤 설치를 다시 진행합니다. 앱 파일 외에 다운로드·준비 작업용 공간도 필요합니다. |
| 브라우저에서 로컬 주소가 열리지 않음 | 같은 기기에서 앱이 켜져 있는지, 터미널에 오류가 없는지 확인합니다. 갤럭시는 Termux가 종료되지 않았는지도 확인합니다. |
| 연결 코드가 만료됐거나 맞지 않음 | 사이트에서 새 코드를 발급받습니다. 이미 사용한 코드는 다시 쓸 수 없습니다. |
| 연결 가능한 기기 수를 초과함 | 사이트 설정에서 사용하지 않는 기기를 해제합니다. 계정당 최대 5대입니다. |
| 기록이 보이지 않음 | 인터넷 연결과 연결한 proving 계정을 확인합니다. 기기 연결이 해제됐다면 새 코드로 연결합니다. |
| 로그인했지만 AI를 쓸 수 없음 | 공부 화면에서 AI 종류·모델을 선택했는지, 사용 승인을 마쳤는지 확인합니다. |
| `git pull`이 변경 파일 때문에 중단됨 | 변경한 파일이 있다는 뜻입니다. 파일을 보관하기 전에 강제로 초기화하지 말고 오류 내용을 확인합니다. |

## 내 데이터는 어디에 있나요?

| 데이터 | 저장 위치 |
| --- | --- |
| 공부 기록·대화·프로필·시험지·답안·메모 | 연결한 proving 사이트 계정 |
| ChatGPT 로그인 정보·기기 연결 정보 | 앱을 실행하는 기기의 `.local` 폴더 |
| 화면 설정·일부 복구용 사본 | 사용 중인 브라우저 |

`.local` 폴더는 다른 사람에게 전달하거나 GitHub에 올리지 마세요. 다른 사람과 앱 소스를 공유하더라도 **각자 본인 계정으로 연결**해서 사용합니다.

앱에서 로그아웃하면 해당 기기의 사이트 연결도 해제됩니다. proving 계정 탈퇴는 사이트에서 진행합니다.
