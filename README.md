# proving local

각자 PC에서 ChatGPT 플랜으로 공부하고, 연결한 proving 계정에 노트·기록을 저장하는 로컬 앱입니다. Node.js 22.6 이상을 사용하세요. 환경변수와 DB 설정은 필요하지 않습니다.

## 설치와 연결

이 폴더가 사용자용 저장소의 루트입니다. 저장소를 다운로드한 뒤 해당 폴더에서 실행합니다.

```sh
npm ci
```

1. https://proving.mynameis.life 에서 본인 계정으로 로그인합니다.
2. 설정의 **연결된 기기**에서 일회용 연결 코드를 발급합니다.
3. 아래 명령으로 이 PC를 연결합니다.

```sh
npm run link -- 발급받은-연결코드
npm run dev
```

http://127.0.0.1:3005 에 접속합니다. 연결 코드로 등록한 사이트 계정의 프로필·기록·탐색·설정을 그대로 사용할 수 있습니다. 공부 화면에서 ChatGPT 플랜을 선택하면 본인 ChatGPT 계정을 AI 용도로 추가 연결합니다. 사이트에 등록한 API 키도 사용할 수 있으며 키는 배포 서버에 보관됩니다. `localhost:3005`로 열어도 위 기본 실행 주소로 자동 이동합니다. 포트 3005를 사용하는 다른 서버는 먼저 종료하세요. 실제 사용 가능 여부는 OpenAI 계정·플랜·정책에 따릅니다.

이후에는 `npm run dev`만 실행하면 됩니다. 업데이트로 페이지 구조가 바뀌면 실행 전에 이전 Next 개발 캐시만 자동으로 정리하며, 연결·로그인 정보는 유지합니다. 종료는 터미널에서 Ctrl+C입니다. 최적화된 실행은 `npm run build` 후 `npm start`를 사용합니다.

## 데이터 보관

- ChatGPT 인증 토큰은 이 PC의 `.local/`에만 저장됩니다. 배포 사이트로 보내지 않습니다.
- 기기 동기화 토큰도 `.local/`에 보관합니다. 다른 사람에게 이 폴더를 전달하지 마세요.
- 공부 대화·초안·기록은 기기 연결 시 선택한 **사이트 계정**에 저장됩니다. ChatGPT 계정은 AI 실행용이며 저장 계정은 바꾸지 않습니다.
- 기기 연결 해제·폐기는 사이트 또는 로컬 앱의 설정에서 합니다. 로컬 로그아웃은 이 기기의 연결도 해제합니다. 다른 사이트 계정으로 연결할 때는 별도 앱 폴더와 브라우저 프로필을 사용해 기존 브라우저 초안이 섞이지 않도록 하세요.
- 완전한 오프라인 앱은 아닙니다. OpenAI와 proving 사이트에 인터넷 연결이 필요합니다.

## 검증

```sh
npm test

npm run build
```

## 개발자용

공개 사이트 주소는 `lib/local-config.mjs`에 있습니다. 비밀정보가 아니며 사용자 설정은 필요하지 않습니다. DB, Supabase 인증, 운영 기능은 이 앱에 포함하지 않습니다. 로컬 앱은 HTTP 루프백에만 바인딩합니다.

## 업데이트

```sh
git pull --ff-only
npm ci
npm run dev
```

이 레포는 proving의 공통 소스에서 자동 생성됩니다. 사이트와 로컬은 동일한 Home·WorkspaceShell·프로필·설정 컴포넌트를 사용하며, UI 수정은 원본 proving에서 진행합니다. 로컬 변경이 있으면 `git pull` 전에 보관하세요. `.local` 인증 정보와 브라우저 저장 데이터는 업데이트할 때 삭제하지 마세요.
